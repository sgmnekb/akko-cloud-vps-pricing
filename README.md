## GT、GIA 和三网优化，三个词差在哪

CN2 是中国电信的下一代承载网，去程和回程都有独立带宽保障，高峰期不容易被挤掉。它内部分两档：GT 相当于普通快车，晚高峰仍有波动；GIA 全程 QoS 保障，路由走 59.43 节点，绕开拥堵的 163 骨干网。普通 163 线路在晚高峰从 40MB/s 掉到 2MB/s 的情况并不罕见，这就是 GIA 被单独拿出来卖的原因。

三网优化是另一个维度的事。电信去程走 CN2、联通走 AS9929、移动走 CMIN2，三家回程都走大陆优化直连，不管你用哪家宽带都不绕路。CMIN2 是中国移动的国际精品网，定位和电信 CN2 GIA、联通 9929 同级。

延迟上要有合理预期，测试点和运营商都会影响结果：

| 节点位置 | 到国内常见延迟 |
| --- | --- |
| 香港 | 40～60ms |
| 日本 | 70ms 起 |
| 美西 | 130～180ms |
| 欧洲 | 180～230ms |

带宽换算成下载速度按 8 比 1 算：30Mbps 约 3.75MB/s，50Mbps 约 6.25MB/s，500Mbps 约 62.5MB/s。

## 500Mbps 配 500GB 流量，哪个先到

这是这类套餐最容易被误读的地方。500Mbps 换算下来约 62.5MB/s，500GB 流量按这个速度持续跑，**大约 2.2 小时**就用完了。所以 500Mbps 是突发峰值，不是能一直维持的吞吐量，真正约束你的是月流量。

把 500GB 摊到 30 天，每天约 16.7GB。按这个额度，每天满速下载四五分钟就到顶。放到具体场景里：

- **个人博客 / 轻量站**：建站月流量普遍在 100～500GB 区间，500GB 这档正好覆盖到上限。日均几千 PV 的图文站跑得动。
- **个人节点**：1080p 视频一小时大约 1.5～3GB，500GB 够 170～330 小时，单人用一个月富余，两三个人同时看就紧张了。
- **文件中转 / 大文件分发**：500GB 撑不住，直接看 1200GB 的 B1 mini 年付或者月付 3000GB 以上的档位。

理解了这个换算，就能明白为什么年付 299 元的套餐只给 1G 内存：它卖的是线路质量和峰值带宽，不是持续吞吐量，硬件配置够跑轻量服务就行。第三方跑分显示入门款 UnixBench 在 690 分左右，跑数据库密集型应用或者高并发服务会吃力。
